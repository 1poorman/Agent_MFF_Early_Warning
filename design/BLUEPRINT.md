# 中频炉水冷系统预警智能体 · 总体蓝图

> 依据：`docs/题目.docx`、`docs/技术实现细节.docx`、知识库 `docs/故障处理.md`
> 架构定位：**大模型主导 + 小模型协同 + 工具调用闭环** 的垂直算法体系

---

## 1. 总体架构

```
┌─────────────────────────────────────────────────────────────────┐
│                        Agent 工作流编排层 (workflow/)             │
│   数据接入 → 边缘特征提取 → 根因推理(防幻觉) → 工具调用/工单 → 反馈归档 │
│   指标: 平均时延 <3s · 异常处理覆盖 100% · 重采≤3次失败告警          │
└──────────┬──────────────────────────────┬───────────────────────┘
           │                              │
┌──────────▼───────────┐       ┌──────────▼───────────┐
│ 边缘端 · 小模型集群    │       │ 云端 · 大模型大脑       │
│ perception/ detection│       │ reasoning/  action/   │
│ ·数据质量管控          │ 异常片段 │ ·知识图谱多跳推理      │
│ ·L1规则引擎 <10ms     │ ──────► │ ·三层防幻觉校验        │
│ ·L2趋势预测 10~30min  │ >60%置信 │ ·置信度分级处理        │
│ ·VAE+孤立森林异常检测  │ 特征上传 │ ·工单生成/分级推送     │
│ ·90%正常数据过滤归档   │ ◄────── │ ·反馈归档/周期微调     │
└──────────────────────┘  基线下发 └──────────────────────┘
```

四大自主执行任务映射（文档 3.1）：

| 任务 | 承载模块 | 性能指标 |
|---|---|---|
| L1 自主异常感知 | `detection/rule_engine.py` | 全链路响应 <10ms |
| L2 自主趋势预测 | `detection/forecaster.py` | 提前量 ≥10min（最高 30min），误差 <5% |
| L3 自主根因诊断 | `reasoning/` | 准确率 ≥85%，误报 <5%，漏报 <3% |
| 闭环处置指令生成 | `action/` | 工单结构化输出 + 分级推送 |

## 2. 模块划分（分块实现）

### M1 `perception/` — 多模态自主感知执行体

| 子模块 | 功能 | 实现要点 |
|---|---|---|
| `ingest.py` | 数据接入 | 当前对接 `simulator/` 输出（CSV/实时流回放）；预留 Modbus/OPC UA/MQTT 适配接口 |
| `quality.py` | 数据质量管控 | 时间戳对齐、缺失插补（同工况加权均值，误差<2%）、异常点剔除、精度 1 位小数、完整度 100% |
| `text_parse.py` | 文本知识抽取 | BERT-CRF 抽取维修记录/操作手册实体关系 → 结构化三元组（初版用规则模板，接口预留） |
| `vision.py` | 图像感知 | 视频帧异常检测（YOLO 类），接口预留，本地有 `yolo26` 环境可参考 |

### M2 `detection/` — 时序预测与异常感知执行体（边缘端小模型）

| 子模块 | 功能 | 实现要点 |
|---|---|---|
| `rule_engine.py` (L1) | 规则预警 | 阈值字典（题目阈值表 + 知识库模块二），**进水温度阈值按季节/环境温度动态修正**；工况动态基线；组合逻辑（如 流量<80% AND 温度>55℃）；含电耗衍生特征规则（单位电耗温升率漂移 → 换热效率衰减） |
| `router.py` | 模型路由 | 按"参数数量 × 预测步长 × 异常置信度"决策分流，见下详述 |
| `fast_track.py` (L2-快) | 快速小步长预测 | 单参数：**STL 时序分解 + GRU+attention**（主力，对齐题目关键技术清单 LSTM/GRU/TCN + 时序分解），步长 1~10min，边缘端毫秒级推理 |
| `fast_anomaly.py` | 快速异常检测 | **VAE 自编码器（仅正常数据训练，重构残差）+ 孤立森林**（残差空间切割），对齐题目异常检测技术清单；残差超动态阈值即上报 |
| `precise_track.py` (L2-精) | 精准多步长多参数预测（增强） | 多参数协同：TCN/PatchTST 做联合预测（对齐题目 TCN 清单）；**Anomaly-Transformer / timesfm 作为精轨增强**做长步长（10~30min）多参数联合预测与关联异常分析，误差 <5% |
| `filter.py` | 特征提纯 | 正常工况归档历史库，异常置信度 >60% 的特征片段上传大模型端，过滤效率 ≥90% |

**模型路由策略（`router.py`）**：

```
                        输入: 实时窗口 + 工况上下文
                                 │
              ┌──────────────────┴───────────────────┐
              │ 路由判定 (轻量决策, <1ms)               │
              └──────────────────┬───────────────────┘
        ┌────────────────────────┼─────────────────────────┐
        ▼                        ▼                         ▼
  单参数 & 短步长          多参数关联 或 长步长        疑似异常片段
  (≤3参数, ≤10min)        (≥4参数 或 10~30min)      (VAE残差/规则越限)
        │                        │                         │
  fast_track:                precise_track:           fast_anomaly:
  STL+GRU+attention          TCN/PatchTST 主力        VAE+孤立森林
  毫秒级, 边缘常驻            +Anomaly-Transformer    残差+融合分
                             /timesfm 增强(按需)
        │                     按需调用(分钟级)              │
        └────────────────────────┼─────────────────────────┘
                                 ▼
                    filter.py 汇总 → 置信度>60% 上传 L3
```

路由规则：
1. **默认走快轨**（STL+GRU）：单参数短步长，覆盖 90% 常规预测需求，边缘端低算力常驻运行；
2. **升级精轨**（TCN/PatchTST 主力，Anomaly-Transformer/timesfm 增强）：当 ①需要多参数联合预测（≥4 参数关联，如温度-流量-压力联动劣化）②预测步长 >10min ③快轨残差超阈值触发复核 —— 任一条件满足即路由至精轨；
3. **异常并行轨**：VAE+孤立森林始终在线扫描，残差异常直接触发精轨复核 + 上报候选；
4. **降级保护**：精轨超时/不可用时自动回退快轨结果并标注置信度降级，保证 7×24 可用性。

### M3 `reasoning/` — 大模型根因推理执行体

| 子模块 | 功能 | 实现要点 |
|---|---|---|
| `knowledge_graph.py` | 五域知识图谱 | "设备-部件-传感器-故障-处置"，源自 `故障处理.md` 结构化（规则集 1/2/3、阈值字典、SOP） |
| `llm_client.py` | 大模型接入抽象 | OpenAI 兼容接口，可切换底座；CoT 提示模板注入工况上下文 |
| `root_cause.py` | 多跳因果推理 | 故障现象 → 图谱路径 → 根因 + 置信度评分，推理链可追溯 |
| `anti_hallucination.py` | 三层防幻觉 | ①物理定律硬约束（热平衡/热力学第二定律）②知识图谱交叉验证 ③置信度<70% 人工兜底；校验不过重试 ≤3 次 |
| `confidence.py` | 置信度分级 | ≥90% 直接输出工单；70~90% 输出 Top3 候选根因；<70% 转人工 |

### M4 `action/` — 闭环处置与自主优化执行体

| 子模块 | 功能 | 实现要点 |
|---|---|---|
| `work_order.py` | 工单生成 | 结构化 JSON：预警级别/触发时间/异常特征/根因推理/防幻觉校验结果/处置 SOP/备件（对齐文档 6.1 展示格式） |
| `notify.py` | 分级推送 | 红(声光+短信+电话→厂长/安全主管/班长)、橙(班长+维修工)、黄(移动端)；推送接口预留 |
| `emergency.py` | 应急预案联动 | 红色预警自动关联应急预案（知识库模块五：突发停电→柴油泵/高位水箱、漏水入铁水→倾炉程序）；移动端同步调取《应急处置 SOP》《点检清单》 |
| `feedback.py` | 反馈归档 | 处置结果（真实根因/处理时长/效果）归档训练样本库，触发周期微调（每周） |

### M5 `tools/` — 工具调用层

| 工具 | 说明 |
|---|---|
| `thermal_balance.py` | 热平衡计算器 Q=c·m·ΔT 校验 |
| `dew_point.py` | Magnus-Tetens 露点计算器（电气柜凝露风险） |
| `ts_features.py` | 时序特征生成（温升率、压力-流量特性偏移度等衍生特征） |

### M6 `workflow/` — Agent 编排层

五节点工作流（文档 5.3），每节点定义输入/输出/校验/异常处理：
1. 多模态数据接入（重采 ≤3 次，失败告警）
2. 边缘端特征提取（≥90% 过滤）
3. 模型根因推理（防幻觉校验，重试 ≤3 次）
4. 工具调用与工单生成（全链路记录）
5. 反馈归档与自主迭代

## 4. 阈值字典（L1 规则基线）

| 参数 | 正常范围 | 预警阈值 | 依据 |
|---|---|---|---|
| 出水温度 | <55℃ | >55℃ | 热交换恶化、加速结垢 |
| 进水温度 | 20~35℃ | >35℃ | **按季节/环境温度动态修正**（夏季基线上浮） |
| 进出水温差 | 10~25℃ | >25℃ | 热平衡约束 |
| 压力 | 150~300 kPa | <150 或 >300 kPa | 密封泄漏/流量不足 |
| 流量 | 额定 ±20% | <80% 或 >120% 额定 | 积热/水压过高 |
| 电导率 | <5 µS/cm（内循环） | >10 µS/cm | 电气击穿风险 |
| **单位电耗温升率**（衍生） | 工况基线 ±15% | 漂移 >15% | 换热效率衰减（水垢前兆），对齐题目痛点"电能耗异常" |
| **压力-流量特性偏移度**（衍生） | P-Q² 曲线基线 ±10% | 偏移 >10% | 管网阻抗变化（堵塞/泄漏前兆），对齐题目衍生特征要求 |

## 5. 实施顺序（与里程碑拆解衔接）

```
M1 感知层  →  M2 L1规则+L2预测+异常检测  →  M5 工具层
→  M3 知识图谱+根因推理+防幻觉  →  M4 工单/推送/反馈  →  M6 工作流编排集成
```

原则：每块独立可验收；模型选型**主力对齐题目关键技术清单**（GRU/TCN + 孤立森林/自编码器/时序分解），Anomaly-Transformer/timesfm 作为精轨增强（参考本地 `Anomaly-Transformer/`、`timesfm/`），保证评审对照友好且效果突出稳定。
