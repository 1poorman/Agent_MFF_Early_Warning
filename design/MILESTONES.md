# 预警智能体 · 里程碑拆解

> 基于 `design/BLUEPRINT.md`，每个里程碑独立可验收（含明确验收标准与测试方法）。
> 验收环境：conda `mff_agent`；测试数据：`simulator/` 生成。

---

## MS1 · 多模态感知层（M1 perception/）

**交付物**
- `perception/ingest.py`：对接 simulator CSV/流回放，输出统一数据帧
- `perception/quality.py`：时间戳对齐、缺失插补（同工况加权均值）、异常点剔除

**验收标准**
| 指标 | 标准 | 测试方法 |
|---|---|---|
| 时间戳完整度 | 100%（无丢包/乱序） | 注入 5% 随机缺失，插补后校验连续性 |
| 插补误差 | <2% | 人为删除已知值，对比插补值与真实值 |
| 数据精度 | 1 位小数 | 全字段校验 |
| 吞吐 | ≥1Hz 实时处理 | 1h 数据回放计时 |

---

## MS2 · L1 规则引擎（M2 rule_engine.py + tools/）

**交付物**
- `detection/rule_engine.py`：阈值字典 + 组合逻辑 + 工况动态基线 + 进水温度季节修正
- `tools/thermal_balance.py`、`tools/ts_features.py`（温升率、P-Q 偏移度衍生特征）
- `tools/dew_point.py`：Magnus-Tetens 露点计算 + 电气柜凝露裕度趋势预测（提前预警凝露短路风险）
- 电耗衍生特征规则（单位电耗温升率漂移、P-Q 特性偏移度）

**验收标准**
| 指标 | 标准 | 测试方法 |
|---|---|---|
| 响应时延 | 单条判定 <10ms | 压测 10 万条均值 |
| 故障召回率 | 100%（突变型越限） | simulator 注入 filter_clog/pipe_leak 强故障，流量<80% 等规则必触发 |
| 正常误报 | <5% | 24h 正常数据全量扫描 |
| 衍生特征正确性 | 温升率/P-Q 偏移与物理重建一致 | 与热平衡方程计算值对比误差<5% |
| 季节修正 | 进水温度阈值随环境温度动态调整 | 模拟夏/冬进水温度基线，校验阈值切换 |
| 露点计算精度 | Magnus-Tetens 公式误差 <0.5℃ | 标准气象数据点校验 |
| 凝露预测 | 裕度 <3℃ 或预测 10min 内跌破即预警 | 构造湿度爬升样本，校验提前量 |

## MS3 · L2 趋势预测 + 异常检测（M2 fast_track/fast_anomaly/precise_track/router）

**交付物**
- `detection/fast_track.py`：STL + GRU+attention 单参数短步长预测（1~10min）
- `detection/fast_anomaly.py`：VAE（正常数据训练）+ 孤立森林
- `detection/precise_track.py`：TCN/PatchTST 主力 + Anomaly-Transformer/timesfm 增强
- `detection/router.py`：双轨路由 + 降级保护

**验收标准**
| 指标 | 标准 | 测试方法 |
|---|---|---|
| 预测误差 | <5%（10min 步长，MAPE） | 正常 24h 数据回测 |
| 预警提前量 | ≥10min（缓变型） | simulator 注入 scale_buildup 缓变故障，从模型告警到实际越限的时间差 |
| 异常检出率 | ≥95% | 4 类故障注入数据全量检出 |
| 误报率 | <5% | 正常数据扫描 |
| 路由正确率 | ≥95%（按规则应走精轨的样本实际走精轨） | 构造多参数/长步长/残差超阈样本集 |
| 降级可用性 | 精轨屏蔽时快轨自动接管并标注 | 故障注入测试 |

## MS4 · 知识图谱 + 根因推理 + 防幻觉（M3 reasoning/）

**交付物**
- `reasoning/knowledge_graph.py`：五域图谱（源自 `故障处理.md` 规则集/阈值/SOP）
- `reasoning/llm_client.py`、`reasoning/root_cause.py`：CoT 多跳推理 + 置信度评分
- `reasoning/anti_hallucination.py`：三层校验（物理硬约束/图谱交叉验证/人工兜底）
- `reasoning/confidence.py`：置信度分级（≥90% 直出 / 70~90% Top3 / <70% 人工）

**验收标准**
| 指标 | 标准 | 测试方法 |
|---|---|---|
| 根因定位准确率 | ≥85% | 4 类故障各 20 例，Top1 命中 |
| 误报率 | <5% | 正常+边界样本 |
| 漏报率 | <3% | 故障样本未检出占比 |
| 防幻觉拦截 | 违背物理定律/图谱外推理 100% 拦截 | 构造幻觉样本（如"出水 10℃ 高于进水 50℃"） |
| 重试机制 | 校验失败重试 ≤3 次，3 次失败转人工 | 模拟校验失败场景 |
| 推理链可追溯 | 每结论可回溯图谱路径 | 输出证据链完整性校验 |

## MS5 · 闭环处置（M4 action/）

**交付物**
- `action/work_order.py`：结构化 JSON 工单（对齐文档 6.1 格式：级别/时间/特征/根因/校验结果/SOP/备件）
- `action/notify.py`：红/橙/黄分级推送（接口 mock + 日志记录）
- `action/emergency.py`：红色预警自动关联应急预案（停电→柴油泵/高位水箱，漏水入铁水→倾炉程序）
- `action/feedback.py`：处置反馈归档 + 训练样本库

**验收标准**
| 指标 | 标准 | 测试方法 |
|---|---|---|
| 工单字段完整性 | 100%（7 类字段齐全） | 各故障类型生成工单逐字段校验 |
| 分级推送正确性 | 级别→渠道→对象映射 100% 正确 | 三级预警各触发，校验推送路由 |
| 应急预案联动 | 红色预警自动挂载对应预案 | 触发红色样本校验预案内容 |
| 反馈闭环 | 反馈入库 + 触发微调标记 | 模拟处置反馈，校验归档与标记 |

---

## MS6 · 工作流编排集成（M6 workflow/）

**交付物**
- `workflow/`：五节点编排（接入→特征提取→根因推理→工具调用/工单→反馈归档）
- 端到端 Demo：simulator 数据 → 三级预警 → 工单输出

**验收标准**
| 指标 | 标准 | 测试方法 |
|---|---|---|
| 端到端时延 | 平均 <3s | 全流程 100 次计时 |
| 异常处理覆盖率 | 100%（节点失败有兜底） | 逐节点故障注入 |
| 数据接入重采 | 失败重采 ≤3 次，超限告警 | 模拟数据异常 |
| 特征过滤效率 | ≥90%（正常数据不进入大模型端） | 统计上传/归档比例 |
| 全流程贯通 | 4 类故障注入均可产出正确工单 | 端到端集成测试 |

## 里程碑依赖与排期

```
MS1 ──► MS2 ──► MS3 ──► MS4 ──► MS5 ──► MS6
（感知）  （L1）   （L2）   （L3）   （闭环）  （集成）
```

每个里程碑完成后运行对应 `tests/test_ms*.py` 验收，通过后进入下一里程碑；
全部通过后汇总测试报告 + 验证数据，形成赛事技术报告交付物。
